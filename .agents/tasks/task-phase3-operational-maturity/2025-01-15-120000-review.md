# Phase 3 Operational Maturity: Cost alerts, secret rotation, versioning, audit export, datetime fix, config validation, graceful shutdown

Seven operational-maturity features added in one batch: a cost alerting service that monitors budget thresholds, secret rotation lifecycle management with API endpoints, an API versioning middleware and router, audit log export with retention policies, a codebase-wide replacement of `datetime.utcnow()` with timezone-aware calls, startup configuration validation, and graceful shutdown hooks in the FastAPI lifespan. The implementation is additive and backward-compatible; all 2519 tests pass.

Watch for: ControlRegistry shutdown persistence creates a **new empty instance** instead of persisting the running one — this will overwrite real state on disk (confirmed). The cost alerting service has no deduplication, so repeated `check_budgets()` calls fire duplicate alerts for the same threshold crossing (confirmed). `telemetry.registry.reset()` is labeled "for testing" and clears all metrics rather than exporting them — calling it on shutdown destroys unscraped data rather than flushing it (confirmed).

**Verdict**: NEEDS_CHANGES

## High-level view

The graceful shutdown logic in `main.py` has three correctness issues: it instantiates a fresh `ControlRegistry` (which loads from disk, persists that loaded-or-empty state right back) instead of referencing the runtime singleton; it calls `registry.reset()` which is a destructive test helper, not an export/flush mechanism; and it logs "Redis connection closing" without actually closing anything. The intent is right but the implementation doesn't achieve its stated goals.

Cost alerting integrates directly with `BudgetEnforcer._budgets` and `._spent` (private internals), creating tight coupling. More importantly, there's no suppression window or deduplication — every poll fires new alerts for scopes that remain over-threshold, which will flood callbacks in any periodic-check deployment.

Secret rotation adds a clean lifecycle model to `FernetSecretBackend` and exposes it through REST endpoints. The rotation trigger endpoint accepts a `new_value` in the request body — the endpoint has no authentication (consistent with the rest of the codebase, but rotation is a privileged operation that warrants auth gating when exposed beyond localhost).

The `deprecated_wrapper` in `VersionedRouter.add_deprecated_route` forces handlers to accept a `Request` parameter and return a `Response`/dict, which is a different signature contract than normal FastAPI endpoints. This limits its use to simple handlers that don't rely on FastAPI's dependency injection.

The `datetime.utcnow()` replacement across 72 call sites is mechanical and correct. The regression test (`test_utcnow_removal.py`) ensures the pattern doesn't creep back.

## ControlRegistry shutdown creates a fresh instance

In `src/nexus/main.py` lines 138–154, the shutdown handler does:

```python
cr = ControlRegistry(persist_path=Path(persist_path_env))
cr._persist()
```

`ControlRegistry.__init__` calls `self._load()`, which reads the file (or starts empty if the file doesn't exist). Then `_persist()` writes that just-loaded state back to the file. The actual runtime state lives in `src/nexus/api/routes/control.py:_registry`, which was never referenced here.

The best case is a no-op (reads file, writes same content back). The worst case — if the file doesn't exist or was corrupted — is persisting an empty registry, overwriting whatever the runtime accumulated. To fix, import the singleton:

```python
from nexus.api.routes.control import get_registry
cr = get_registry()
# Only persist if it has a path configured
```

## Telemetry reset on shutdown

`registry.reset()` in `src/nexus/telemetry.py` is:

```python
def reset(self) -> None:
    """Reset all metrics (for testing)."""
    with self._lock:
        self._metrics.clear()
```

This deletes all accumulated counters and histograms. If a Prometheus scraper hasn't collected the final interval's data before shutdown, that data is gone. The comment says "for testing" — calling it in production shutdown contradicts its purpose. Remove the call, or if export is intended, implement an actual push to a metrics sink.

## Cost alert deduplication gap

`CostAlertService.check_budgets()` in `src/nexus/governance/cost_alerting.py` fires an alert for every scope that exceeds `warn_pct` or `critical_pct` on every invocation. The `_fired_alerts` list grows monotonically and callbacks are invoked every time.

In any scheduled polling scenario, a scope that stays at 96% of budget will generate a CRITICAL alert on every check. A production-ready alerting service needs either:
- A `_last_severity` map that suppresses re-fires at the same level, or
- A cooldown period per scope before re-alerting.

## Rotation API security surface

The rotation router (`src/nexus/api/routes/rotation.py`) exposes four endpoints:
- `POST /api/v1/rotation/policy` — sets rotation policy
- `GET /api/v1/rotation/status/{ref}` — checks rotation status
- `POST /api/v1/rotation/trigger` — rotates a secret (accepts `new_value` in body)
- `GET /api/v1/rotation/needs-rotation` — lists secrets needing rotation

`trigger` is categorically different from read endpoints — it accepts a plaintext secret value and writes it into the encrypted store. If this system ever serves non-localhost traffic, this endpoint is the highest-priority candidate for auth gating.

The `get_rotation_status` endpoint accesses `backend._rotation_policies` (private attribute) directly on line 140. A public `get_rotation_policy(ref)` method would decouple the route from the backend's internal storage layout.

## Deprecated route wrapper signature

`VersionedRouter.add_deprecated_route` wraps the endpoint function:

```python
async def deprecated_wrapper(request: Request) -> Response:
    result = await original_endpoint(request)
    ...
```

The original endpoint must accept exactly `(request: Request)` and return either a `Response` or a dict. Standard FastAPI endpoints that use path parameters, query params, or dependency injection via function signatures won't work through this wrapper — FastAPI's dependency resolution is bypassed because the wrapper takes `Request` as its only parameter.

The tests confirm this limitation: all deprecated endpoints in tests accept `Request` explicitly.

## Redis shutdown does nothing

```python
if redis_url:
    shutdown_logger.info(
        "Redis connection closing (url=%s)",
        redis_url.split("@")[-1] if "@" in redis_url else redis_url,
    )
```

This logs that Redis is closing but performs no actual close/disconnect. There's no Redis connection object tracked in the lifespan. The log message claims a state transition that doesn't happen — misleading for anyone debugging connection issues post-shutdown.

## Test coverage gaps

Not tested: the ControlRegistry shutdown logic (the bug described above isn't exercised), concurrent access to `AuditExporter` under actual thread contention, cost alert callback exception handling (if a callback raises, subsequent callbacks for the same alert are skipped), deprecated route interaction with FastAPI's OpenAPI schema generation.
