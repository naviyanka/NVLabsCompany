# Phase 2 Reliability: Redis state, pluggable Hive, Docker sandbox, L1 persistence, LLM circuit breaker, degradation endpoint

Six reliability primitives across governance, communication, evolution, memory, adapters, and API layers. All nine v1 issues and all four v2 issues have been resolved: the HiveBackend protocol is fully async with recovery cooldown, FileStateBackend uses bijective percent-encoding, HiveManager uses an instance-level thread pool with configurable timeout, RuntimeError is removed from transient exceptions, the Docker sandbox includes `--tmpfs /tmp` and a fallback indicator, and the degradation endpoint uses a Redis singleton.

Watch for: The degradation endpoint's `overall_status` logic still contains an unreachable `else` branch — harmless but dead code (confirmed). The `RedisStateBackend` imports `time` locally in three separate methods instead of at module level (confirmed).

**Verdict**: APPROVED

## High-level view

The state backend provides `StateBackend` Protocol with Redis and file implementations, factory with fallback, bijective percent-encoding for filesystem keys, and cooldown-based recovery for Redis.

The HiveManager accepts an optional async `HiveBackend`, bridges sync callers via an instance-level `ThreadPoolExecutor` with configurable timeout, and `RedisHiveBackend` has the same recovery-cooldown pattern as `RedisStateBackend`.

The LLM circuit breaker classifies only `TimeoutError`, `ConnectionError`, `OSError`, and `IOError` as transient. All other exceptions propagate immediately without tripping the breaker.

## Degradation overall_status logic

```python
if all(s == "full" for s in statuses):
    overall = "full"
elif any(s == "unavailable" for s in statuses):
    overall = "degraded"
elif any(s == "degraded" for s in statuses):
    overall = "degraded"
else:
    overall = "full"
```

The `else` branch can only fire if no status is "full", "unavailable", or "degraded" — impossible given every check function returns exactly one of those three values. The v1 review flagged this; a comment was added to the third branch, but the unreachable else remains.
